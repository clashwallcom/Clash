## 门户怎么用

1. 用顶部**本页导航**跳到桌面 / 移动 / 教程 / 归档 / 节点其中一面墙  
2. 在对应墙上点 **Releases** 下载，再用同名**站内教程**对照设置  
3. 导入订阅 → 测延迟 → 再开系统代理或 TUN  
4. 需要总览发布页时走 [Clash Releases](https://clashwall.com/clash-releases/)；需要节点对照时走节点墙

常见踩坑：装到仿冒站安装包、同时开两个客户端抢系统代理、把已停更的 CFW / 原版 CFA 当新装首选。
